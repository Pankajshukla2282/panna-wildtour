## Blog Template (Use for every post)

4. Practical checklist/table

## On-Page SEO Checklist Per Post

- Primary keyword in title, first paragraph, one H2
- Meta description under 155 chars
- Add FAQ schema block (if available)
- Add 1 image with descriptive alt text
- Add CTA in middle and end of post
